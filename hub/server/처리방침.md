# IRIS 메신저 처리방침

이 문서는 공식 허브(운영자: Sejun Ham, `hub-ref.json` 기준 Supabase 프로젝트)가 사용자에 대해 어떤 정보를 다루는지를 밝힙니다. 자기 허브를 세운 운영자는 이 문서를 자신의 상황에 맞게 고쳐 써도 됩니다.

## 수집하는 것

- 이메일 주소(로그인용)
- 표시 이름
- 공개 열쇠(public key) — 메시지 암호화에 쓰이며, 그 자체로는 메시지를 열 수 없습니다
- 연락처 관계 — 누가 누구와 연결되어 있는지(수락된 관계, 대기 중인 관계, 차단 관계)
- 메시지를 보내고 받은 시각(발신 시각·수신 시각) — "누가 누구에게 언제 몇 번 보냈는지"에 해당하는 메타데이터

## 절대 수집하지 않는 것

- 메시지 내용(평문) — 서버에는 암호문만 저장되며 서버는 이를 해독할 수 없습니다
- 파일 내용
- 사용자의 작업 내용·작업 과정·세션 기록

## 보관 기간

- 배달이 확인된 메시지는 **배달 후 30일**이 지나면 서버에서 자동 삭제됩니다.
- 계정을 삭제(탈퇴)하면 **즉시** 그 사용자와 관련된 모든 줄(프로필·연락처·메시지·초대)이 삭제됩니다.
- 첨부 파일(Storage)은 배달 여부와 무관하게 업로드 후 90일이 지나면 삭제됩니다.

## 나이 제한

이 서비스는 **만 14세 이상**만 사용할 수 있습니다. 로그인 화면에서 "만 14세 이상이며 처리방침을 읽었습니다"에 동의해야 계속 진행할 수 있습니다.
